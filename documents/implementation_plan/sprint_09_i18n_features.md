# Sprint 9: Implementation Plan — i18n, Commute & Advanced Features

## Goal
Add internationalization (i18n) support, commute scoring for properties, and advanced listing features.

## Proposed Changes

### 1. Internationalization (i18n)
- React-i18next integration
- English and Hindi translations
- Language switcher in Layout
- All UI strings externalized to translation files

### 2. Commute Scoring
- Calculate commute time from property to key locations
- Display commute badges on PropertyCard
- Google Distance Matrix API integration

### 3. Advanced Listing Features
- Featured properties carousel
- Amenity-based filtering with chips
- Sort options (price, date, relevance)
- Pagination for large result sets

## Verification
- Switch language → All strings translate → Commute scores visible → Featured listings highlighted
